# Convergence integration evidence (Godot 4.4.1, xvfb + software OpenGL, 2026-09-05)

Integration certification, not visual-quality certification: each capture was
inspected for world displaced from terrain, road/building misalignment,
floating citizens, off-road vehicles, wrong scale, broken interior transition,
duplicate layers, and any return of the capsule NPC representation.

| file | scene | what it shows |
|---|---|---|
| `houston_iso_exterior.png` | `IsoScreenshot` (IsometricWorld + live bridge) | compiled Houston: buildings on the ground, roads/sidewalks aligned, humanoid citizens, parked vehicles, regional terrain attached |
| `houston_iso_crowd.png` | same | the crowd around the player (humanoids, MultiMesh) |
| `houston_iso_wide.png` | same | zoomed-out urban view, residential architecture grammar, big-box/commercial masses |
| `houston_iso_interior_cutaway.png` | same, after `ENTER_BUILDING` | authoritative interior (building 0, clinic): fixtures == containers, cutaway walls, exit prompt |
